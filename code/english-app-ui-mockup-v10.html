设计规范速查 · v10 真机反馈

沿用 v6~v9 规范（HyperOS / MiSans / #3482FF / #FF6900 / Wallet 卡 / 方案 A 等宽轮播 / 大圆顶录音组件）。本页只列 v10 变更。

① 跟读页底部布局（两方案）

现状问题真机：滚动区下浮着「播放圆钮+文字」与「灰胶囊」两个元素——灰胶囊像禁用态、播放与跟读关系不明、中间大片留白
方案一（推荐）原声播放收成句子卡右上 38dp 小圆钮 + 进度环（播放中显示暂停 icon + 环形进度 + 「原声播放中」小标）；底部只留跟读胶囊一个主角 + 上一句/下一句小钮行
状态逻辑播放中：胶囊灰底文案「听完这句，跟读」（不再是禁用感的纯灰）；播放结束：胶囊点亮橙渐变 + 顶部提示消失——「先听后说」用状态色表达，不用禁用
方案二（对比）一排两钮：56dp 播放大钮 + 跟读胶囊水平并排——直达性最好，但跟读主角感被稀释、胶囊宽度受挤压，且播放/跟读无先后引导
推荐理由动线顺序（听→说）内建于布局；底部单主角层次清晰；句子卡信息密度提高（播放状态就近展示）；同时解决留白失衡
顺带真机的「通过本关卡，你将学会什么」大列表压缩为 chips 行（≤3 枚），把版面还给跟读

② 录音圆顶修正（对比 v9-dome 实现）

问题诊断a) 升起用 overshoot spring（.3,1.2,.4,1）产生回弹，观感"生硬"；b) 圆顶 118dp 偏矮、弧线不够舒展；c) mic 与提示文案层级贴近、缺少呼吸空间；d) 背景压暗 .55 不够、无 blur，圆顶浮不出来
修正 1 曲线升起改 cubic-bezier(.22,.9,.34,1) 380ms——先快后缓、无回弹（"涌上来"而非"弹上来"）；回落 240ms ease-in
修正 2 形态高 118→140dp；宽度 132%→150% 超出屏宽，弧顶更平缓；三段渐变（#6BB0FF→#3482FF→#2468D8）加底部暗部，弧面更立体
修正 3 层级提示「松开跟读」固定于弧顶上方 ~30dp（不随圆顶动）；计时与「上滑取消」合并进副行；mic 32dp 白色 + 投影嵌于弧心
修正 4 背景压暗 .55→.6 + blur(2px)，圆顶投影加强（-14dp 50dp 大范围蓝晕）
波浪两层弧面高光带 translateY ±5dp / scaleX ±3% 交错（3.2s/4.1s），比竖条声波更贴圆顶形态；仍是纯循环假动画
取消态整体渐变转红（#F58A8E→#E5484D→#C23338 三段）、scale .95、波浪停摆，提示转红「松开取消 · 录音作废」；阈值 ≥56dp 不变

③ 单词页（两态 + 顶部信息区）

顶部信息区蓝渐变头卡「我的生词本」：总词数大数字（45 个词）+ 三列小计（待复习 5 / 已掌握 32 / 学习中 8）+ 右上白 duotone 星形水印（与关卡卡语言同源）
复习入口白卡「今日复习 · 到期 5 词（橙强调）· 跟读一遍即过」+「开始复习」蓝胶囊——固定在头卡下，有词才出现
有词列表词 17px + 音标释义 12px；副行 = 来源徽标（蓝=对话 / 紫=NCE L1）+ 复习倒计时（今天到期/1 天后橙色强调，3 天后起灰色）；右侧 34dp 发音圆钮
空态倾斜卡堆插画（第三张虚线"+词"暗示可填）+「生词本还是空的」+ 两张收词路径卡（跟读点句中生词 / 对话纠错自动收集）+「去读第 1 关」CTA——把空态做成引导，不做报错感
口径收词次日到期、跟读一遍即过（沿用）；倒计时数字与 1/3/7 天复习周期一致

④ 统计页取舍稿（待 PM v4 校准）

保留 4 项连续打卡（橙渐变火苗卡 + 最佳纪录 +「今天还差 1 分钟」行动提示）；累计跟读 126 句；本周时长 38 分钟；累计开口 5.2 小时（三列数据块）

原则只显示帮用户"坚持"的数据（进度感/连续感/临近目标），不显示"分析"数据；页脚一句口径「开口满 3 分钟即计打卡」
