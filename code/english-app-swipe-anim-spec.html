滑动切词 · 参数规范表（工程师照表实现）

坐标系：卡水平位移 x（px，右为正）、旋转 rot（deg）、新卡缩放 s2。
核心原则：拖拽、滑出、归位共用一套 spring 积分器，提交时把拖拽末速度 vx 作为 spring 初速度——不允许"松手后重新 tween"，这是手感连贯的唯一要点。

A. 拖拽阶段（pointer down → move）

跟随x = dx × follow，follow 默认 1.0（1:1 跟手）；单指水平分量，竖直分量忽略
旋转rot = clamp(dx × rotK, ±10°)，rotK 默认 0.05 deg/px——卡片随拖拽轻微倾斜，方向感来源
新卡预备s2 = lerp(prep, prep+0.04, min(|x|/xThresh, 1))，y2 = lerp(8, 3, 同上)——后层卡随拖拽进度缓缓"迎上来"，不跳
位移上限|x| > 0.5×stage 宽后按 0.85 次幂阻尼衰减，防拖出无边
提交判定松手时 |x| ≥ xThresh（默认 0.25×卡宽 ≈ 63px）或 |vx| ≥ 1500px/s（快甩）——vx 由最近 2~3 帧 move 采样计算
方向浮标|x| > 0.3×阈值时显示「换一个」淡入（透明度随进度），提交瞬间到达 1——给方向确认感

B. 提交阶段（旧卡滑出 ∥ 新卡归位，同一时刻启动）

旧卡滑出spring：初值 x、初速 vx（继承拖拽），目标 sign(x+vx) × (stage半宽 + 卡宽)；刚度 kOut=320、zeta=1.0（临界阻尼，不带回调弹跳）；rot 追加到 sign×12°；透明度 1→0 在行程后 45% 线性淡出
快甩加权若由速度判定触发（|vx|≥阈值而位移不足），滑出目标不变，但 spring 初速已是高 vx——自然飞得更快，无需额外时长分支
新卡归位spring：scale prep+0.04→1、y→0，刚度 kHome=380、zeta=0.88（欠阻尼 1 次轻收，无可见跳动）；与旧卡滑出同一帧启动
出牌观感旧卡 opacity 到 0 后立即从层上移除并回填到底层堆（换词、重置 scale .88）；不等归位完成

C. 弹回阶段（未过阈值）

双卡回位同一帧启动：当前卡 spring 回 x=0、rot=0（kHome, zeta）；新卡 spring 回 s2=prep、y=8
手感初速同样继承 vx——轻轻一拨卡片"滑"回来而不是"吸"回来；zeta < 0.9 时有约 1 次微过冲，即 iOS 相册的"果冻感"，默认 0.88
边界弹回期间再按住卡片 = 无缝接管为拖拽（把 spring 当前 x/v 接进拖拽状态）——连拨不卡手

D. 帧循环与工程实现要点

积分器半隐式欧拉：每帧 v += (-k(x-target) - c·v)·dt; x += v·dt；c = 2·zeta·√k；dt = clamp(frameΔt, 0, 32ms)，标签页切回不跳变
状态机idle → dragging → settle(out∥home) → idle；settle 进行到 60% 即解锁新一轮拖拽（连滑不等待）
Compose 对应Animatable + animateTo(spring(stiffness=k, dampingRatio=zeta, visibilityThreshold…))，滑出用 initialVelocity = vx；位移上限用 draggable 的 onDelta 里做幂衰减；禁用默认 animateDecay 惯性（由 spring 初速替代）
禁止项禁止松手后用固定时长 tween 重演位移（两段速度不衔接=手感割裂的根源）；禁止新卡从大幅 y 偏移"托起"（纵跳感根源，y 幅度 ≤8dp）；禁止旧卡与新卡交叉淡入淡出（半透明重叠感根源）
性能只动 transform/opacity；卡 ≤3 张在层上；swipe 期间关闭阴影动画（阴影恒定）

E. 预设参数（对应面板三档）

Apple 克制follow 1.0 · thresh 0.25 · vx 1500 · rotK 0.05 · prep 0.93 · kOut 320 · kHome 380 · zeta 0.88 —— 默认推荐
黏滞跟手follow 1.05 · rotK 0.08 · kHome 300 · zeta 0.75 —— 果冻感更强，拨回有明显回弹
轻快利落vx 1100 · kOut 420 · kHome 520 · zeta 1.0 —— 快切词流，几乎无弹性
调参口径先在原型上调到满意 → 把 8 个值抄进 Compose 常量；用户点头后参数冻结，不再"感觉改"
