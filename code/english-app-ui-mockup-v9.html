设计规范速查 · v9 交互与视觉升级

沿用 v6/v8 规范（HyperOS / MiSans / #3482FF / #FF6900 / Wallet 卡 / 方案 A 等宽轮播）。本页只列 v9 新增，口径对齐 PM english-app-v3-requirements.md。

① 微信式录音浮层 · 状态机与动效

形态底部大圆顶（微信式圆弧，配色改用 App 主色蓝 #3482FF 渐变，不用微信绿）：全宽、高约 118dp、椭圆弧顶（border-radius 50%/100%）；中央白色麦克风图标；对话/课文跟读/单词跟读三页共用一套组件，仅提示文案随场景变
文案红线状态文案一律 ≤8 字：「松开跟读」「松开取消」「识别中…」「没听清，再试」
态 1 按下圆顶自底缘弹性升起 400ms cubic-bezier(.3,1.2,.4,1) translateY(100%)→0；背景压暗 rgba(8,10,16,.55) 200ms；按钮转按压态 scale .96
态 2 录音中弧顶上方蓝字「松开跟读」+ tabular 计时每秒刷新；圆顶表面两层弧面缓慢起伏（2.6s/3.4s 交错 alternate，纯循环假动画，SpeechRecognizer 无实时音量，禁止音量联动）
态 3 上滑取消上滑 ≥56dp 阈值：圆顶转红渐变（#F26D72→#E5484D）、弧线略收（scale .94）、波浪停摆，提示转红「松开取消」+「录音作废」；未过阈值松手圆顶回落 240ms spring
态 4 松手发送圆顶下滑收回 180ms → 进入现有 ASR 比对流程
态 5 识别成功浮层已收起，页面内出结果（与现有一致）
态 6 识别失败页面内 toast「没听清，再试」≤8 字、300ms 抖动一次，不弹浮层打断
取消语义取消的录音作废、不计开口时长；最短录音 300ms，不足按误触取消

② 通关收获 + 里程碑徽章

收获卡复用关卡卡橙渐变语言 + 白 duotone 星形水印；「通关可得」小标 + 内容 ≤20 字（"5 个表达 + 1 个句型"）+ 连闯激励一行（"连闯 3 关，越说越顺！"）
勾选动画「本关你学会了」清单逐条勾选：checkIn spring scale 0→1，间隔 500ms 依次点亮（3 条约 1.5s 完成）；图标与进关页学习目标一一对应
里程碑徽章只做 4 档：10 / 50 / 100 / 276 关；几何风单色 SVG（入门=星形旗 / 坚持=书本纹 / 百关=锯齿勋章 / 通关=钻石）；已解锁彩色 + 未解锁灰态 opacity .38
进度指引顶部 4 段进度条（10 关 ✓ / 50 关·还差 38 / 100 关 / 276 关）；徽章只在达成时出现，不做每日打卡装饰
连闯 3 关不设徽章，以成绩单即时激励文案呈现（保持 4 档克制口径）

③ 关卡卡 AI 插画位 + 验收 checklist

推荐 C背景水印：白单色 duotone（透明度 ≤35%、sheen 之下）、主体偏右上（与原 glyph 位一致）、左下白字区留空——渐变语言不变、白字对比度天然安全
备选 A顶部横幅：插画突出但卡面割裂、Wallet 一体感减弱——不作首选
备选 B左侧小图：插画缩为词条缩略、场景感尽失——不作首选
示例L1 Excuse Me! = 问候场景（双人剪影+气泡）；L2 Sorry, sir. = 找伞场景（雨伞+雨滴）；构图重心右上，左下 1/3 留白
checklist 1 构图 硬性项主体位于卡面右上 1/3 区域；左下信息区无主要元素入侵；每卡元素 ≤8；景深 ≤2 层。不达标直接重生成/回退 glyph，不打折通过
checklist 2 风格 硬性项纯白单色 duotone（白 18%~32% 两档）；线条 0、仅色块；无文字入画（气泡内不放字）；276 张同一 prompt 模板批量生成。不达标直接重生成/回退 glyph
checklist 3 对比度 硬性项叠加后左下信息区背景亮度 ≤30%；白字（含 11.5px 副行）对比 ≥4.5:1；sheen 层在最上不变；锁定卡全卡 saturate(0)。不达标直接重生成/回退 glyph
兜底离线批量生成 276 张，单张失败回退现有 glyph 渐变卡，永不空卡

④ 点词释义底部弹层

触发点句中可点词（浅蓝墨线提示）；弹底部词卡（非气泡——不遮句子、拇指可达）；跟读页与对话页共用同一组件
词卡结构grabber → 词 24px + 发音圆钮 + 「加入单词本」蓝胶囊 → 音标/词性 → 中文释义 → 例句（优先本课原句，标"本课原句"）→ 来源徽标「NCE 第 1 课」
已收藏态按钮转绿「已在单词本」+ 句中墨线变实线绿、译文对应词转绿——一眼可辨不重复打扰
关闭点遮罩或下滑关闭，200ms；不挡跟读流程
与收词面板区分点单个词 = 查词+收词（底部词卡）；长按整句 = 整句收词面板（v7 bottom sheet）——两入口并存互不打扰
防误触按住跟读手势期间禁用点词；词卡打开时点跟读按钮先关词卡

⑤ 沿用项

不变方案 A 等宽轮播、单词快捷卡、成绩单算分与鼓励式文案、1/3/7 复习、打卡口径、Tab 命名、锁定卡 saturate(0)
替换旧件按钮内声浪条（现实现）退役，由底部大圆顶录音组件整体替代；按钮回归静态样式 + 按压态
动效基调统一 HyperOS spring cubic-bezier(.3,1.2,.4,1)；浮层进出 180~260ms，循环动画 ≥1.6s 缓慢呼吸，避免焦虑感
